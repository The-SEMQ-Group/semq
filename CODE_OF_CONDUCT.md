# Code of Conduct

The SEMQ project follows the **Contributor Covenant v2.1**.

Read the full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Everyone who takes part accepts this contract. That includes
contributors, maintainers, reviewers, and anyone who opens an issue. It
applies in every SEMQ project space: this repository, the related
discussions, and project events.

## Reporting

To raise a concern about conduct, write to **conduct@thesemqgroup.ai**. The
maintainers read every report and follow the Enforcement section of the
Contributor Covenant.

For a security vulnerability rather than a conduct concern, follow
[`SECURITY.md`](SECURITY.md) instead.
