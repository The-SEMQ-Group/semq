# How-to guides

Pick a task and follow its steps. If this is your first state, start with
the [quickstart](../quickstart.md). Read [Concepts](../concepts.md)
for the model behind an operation, or the [API reference](../reference/index.md)
for a signature.

## Gate and configure

- [Gate a rebuild](gate-a-rebuild.md): measure a floor from null rebuilds and gate a candidate, in code or from the command line.
- [Choose a configuration](choosing-a-config.md) for your vectors: operator, bins, sectors and scale.

The [benchmarks](../benchmarks/index.md) collect measured results and link to
the methods used to reproduce them.
